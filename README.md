DreamScape — A Space for Dreams & Imagination🌙
Project Overview
DreamScape is a creative website designed around dreams, imagination, and storytelling. Its calm, moonlit visual theme provides a welcoming space for users to explore their imagination and begin their dream-journaling journey.
This project was created as part of the Generative AI assignment for the BS Information Technology program at Superior University.
Project Objectives
- Explore how AI-assisted tools can support website development.
- Create a visually appealing website around a creative concept.
- Apply learning through a practical academic project.
- Develop an understanding of project publishing and version control with GitHub.
AI Tool Used
- AI-assisted development tool: Bolt.new
Website Features
Based on the current website design:
- DreamScape landing page: A creative homepage focused on dreams and imagination.
- Moonlit visual theme: A night-sky-inspired design with stars and a moon logo.
- Explore Your Imagination: A button inviting users to explore the creative experience.
- Start Dream Journaling: A button introducing the dream-journaling experience.
- Published website: The project is available online through its live link.
